# web2supernote
**A browser extension that saves web pages as PDFs and uploads them to Supernote devices. Supports Chrome browser.**

## Features

- Convert the current web page to PDF
- Support for custom server addresses
- Save history of recently used server addresses
- Multi-language support (including Chinese, English, Japanese, German, Spanish, French, Italian, Polish, Portuguese, Russian, Korean, etc.)
- Compatible with Chrome browser

## Installation Instructions

### Chrome Version

1. Download the `chrome` directory from the project.
2. Open the Chrome browser and navigate to the Extensions page (chrome://extensions/).
3. Enable "Developer Mode."
4. Click "Load unpacked extension."
5. Select the downloaded `chrome` directory.

## Usage Instructions

1. Click the extension icon in the browser toolbar.
2. Enter the server address of the Supernote device in the input box.
3. Click the "Upload" button.
4. Wait for the PDF generation and upload to complete.

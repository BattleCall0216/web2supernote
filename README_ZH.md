一个浏览器扩展，可以将网页保存为 PDF 并上传到 Supernote 设备。支持 Chrome 浏览器。

## 功能特点

- 将当前网页转换为 PDF
- 支持自定义服务器地址
- 保存最近使用的服务器地址历史
- 多语言支持（中文、英文、日文、德文、西班牙文、法文、意大利文、波兰文、葡萄牙文、俄文、韩文等）
- 支持 Chrome浏览器

## 安装方法

### Chrome 版本

1. 下载项目的 `chrome` 目录
2. 打开 Chrome 浏览器，进入扩展程序页面 (chrome://extensions/)
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择下载的 `chrome` 目录

## 使用方法

1. 点击浏览器工具栏中的扩展图标
2. 在输入框中输入 Supernote 设备的服务器地址
3. 点击"上传"按钮
4. 等待 PDF 生成和上传完成
